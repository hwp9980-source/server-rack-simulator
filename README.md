# 서버랙 3D 시뮬레이터

서버랙 구성을 실제 장비 도입 전에 **가상 3D 환경에서 미리 시뮬레이션**해 볼 수 있는 웹 애플리케이션입니다.
카탈로그에서 시판 구성품(서버·스토리지·스위치·UPS 등)을 선택하면 절차적으로 3D 모델링되어 랙에 배치됩니다.

![screenshot](docs/screenshot.png)

## 주요 기능

- **19인치 표준 랙 3D 시뮬레이션** — 캐비닛 **높이를 2U~60U**, **깊이를 500~1200mm** 범위에서
  자유 조절 (± 스테퍼·직접 입력·프리셋), U 눈금 표시
  - 높이 축소 시 잘려나갈 구성품, 깊이 축소 시 후면이 돌출될 구성품이 있으면 경고 후 진행
  - 프레임(베이스·상판·기둥·레일) 투명화 토글로 내부 장비를 가리지 않고 확인 가능
- **구성품 카탈로그** — Dell·HPE·Supermicro·Lenovo 서버, Synology·NetApp 스토리지,
  Cisco·Arista·Juniper·MikroTik·TP-Link 스위치(CRS326/328/354/518/804, JetStream 등),
  APC·Eaton UPS/PDU 등 실제 시판 장비 사양(U 높이·깊이·전력·무게·가격) 기반
- **선반형(비-랙) 기기** — 노트북·ATX PC 케이스·Wi-Fi 공유기·NVIDIA DGX Spark·Mac Studio/mini·
  Synology 데스크탑 NAS 등은 랙 슬롯이 아닌 **선반(고정 선반 1U) 위**에 배치
  - 한 선반에 여러 기기를 좌→우로 이어붙여 배치(폭이 남으면 자동으로 다음 자리에 배치),
    선반을 제거하면 위에 놓인 기기도 함께 정리
  - 배치 후에도 선반 평면 위에서 좌우로 드래그해 자유롭게 재배치 가능 (다른 기기와 겹치면 이동 불가)
- **절차적 3D 모델링** — 드라이브 베이, 네트워크 포트, LED, LCD, 통풍구,
  (선반형 기기는) 노트북 화면·타워 강화유리·공유기 안테나 등 유형별 디테일 자동 생성
- **직관적 배치** — 카탈로그 클릭 → 랙의 원하는 U 위치(또는 선반 위 빈 자리) 클릭으로 장착
  - 배치 가능/불가 위치를 초록/빨강 고스트로 미리보기
  - `Shift`+클릭으로 연속 배치, `ESC`로 취소
  - 슬롯 충돌(이미 장착된 위치)·선반 공간 부족 자동 차단
- **편집** — 드래그로 위치 이동, 선택 후 ▲/▼ 버튼 또는 `Shift`+`↑`/`↓`로 위아래 이동
  (인접 칸이 차 있으면 장애물을 건너뛰어 다음 빈 자리로), 복제·제거, `Delete` 키 제거
- **실시간 집계** — 사용 U 수, 총 소비전력(W), 총 무게(kg), 총 도입 비용(₩) — 선반 위 기기도 합산
- **저장/공유** — 브라우저 자동 저장(localStorage), JSON 내보내기/불러오기 (선반 위 기기 포함)
- **카메라 조작** — 정면/후면/사선 프리셋, 마우스 궤도 회전·줌,
  화면 우하단 조작 패드(회전 4방향·확대/축소·시점 초기화, 누르고 있으면 연속 동작),
  키보드 단축키(`←→↑↓` 회전, `+`/`-` 줌, `Home` 초기화)

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
```

프로덕션 빌드:

```bash
npm run build      # dist/ 에 정적 파일 생성
npm run preview    # 빌드 결과 미리보기
```

## 조작법

| 동작 | 방법 |
|---|---|
| 구성품 장착 | 카탈로그에서 클릭 → 랙의 원하는 위치 클릭 |
| 연속 장착 | `Shift` + 클릭 |
| 장착 취소 | `ESC` 또는 카탈로그 항목 재클릭 |
| 선반형 기기 배치 | 카탈로그(데스크탑 탭)에서 클릭 → 선반 위 빈 자리 클릭 |
| 유닛 선택 | 랙의 유닛(또는 선반 위 기기) 클릭 |
| 유닛 이동 | 유닛을 위/아래로 드래그 · 선택 후 ▲/▼ 버튼 · `Shift`+`↑`/`↓` |
| 선반형 기기 이동 | 선반 위에서 좌우로 드래그 (다른 기기와 겹치면 이동 불가) |
| 유닛 제거 | 선택 후 `Delete` 키 또는 제거 버튼 |
| 카메라 회전 | 빈 공간 드래그 · 조작 패드 ◀▶▲▼ · 방향키 |
| 확대/축소 | 마우스 휠 · 조작 패드 ＋/－ · `+`/`-` 키 |
| 시점 초기화 | 조작 패드 ⟲ · `Home` 키 |

## 기술 스택

- [Three.js](https://threejs.org/) — 3D 렌더링 (모든 장비 모델은 외부 에셋 없이 절차적 생성)
- [Vite](https://vitejs.dev/) — 개발 서버 및 번들링
- 순수 JavaScript (프레임워크 없음)

## 구조

```
index.html          앱 레이아웃 (툴바·카탈로그·뷰포트·인스펙터)
src/
  main.js           씬 구성, 인터랙션, UI 로직
  rack.js           랙 프레임 모델링 + 슬롯 점유 관리
  models.js         구성품 절차적 3D 모델링 (유형별 전면 디테일)
  catalog.js        구성품 카탈로그 데이터 (실제 장비 사양)
  style.css         다크 테마 UI
```

## 카탈로그 확장

`src/catalog.js`의 `CATALOG` 배열에 항목을 추가하면 됩니다:

```js
{
  id: 'my-server', category: 'server', vendor: 'MyVendor',
  name: 'Custom Server X1', u: 2, depth: 750, power: 900, weight: 24,
  price: 10000000, accent: 0xff8800, style: 'server', bays: 12,
}
```

`style`은 `server` / `storage` / `switch` / `patch` / `ups` / `pdu` / `kvm` / `shelf` / `cable` / `blank` 중
선택하며, 유형에 맞는 전면 디테일이 자동 모델링됩니다.

선반 위에 놓이는 **선반형(비-랙) 기기**는 `category: 'desktop'`, `u: 0`으로 지정하고
`width`/`depth`/`height`(mm)로 실제 크기를 표현합니다:

```js
{
  id: 'my-mini-pc', category: 'desktop', vendor: 'MyVendor',
  name: 'Mini PC X1', u: 0, width: 150, depth: 150, height: 50,
  power: 65, weight: 1.0, price: 900000, accent: 0x4f8cff, style: 'mini',
}
```

`style`은 `laptop` / `tower` / `router` / `mini` / `nas-tower` 중 선택합니다.
